# TechTreasure Blog – Design Guide

## 1. Color Palette

The website follows a Cyberpunk Neon theme.

- Background: Dark black (#080812)
- Primary Color: Neon purple (#A855F7)
- Accent Color: Electric blue (#22D3EE)
- Text Color: White and light gray

These colors create a futuristic and modern appearance.

## 2. Typography

The website uses Segoe UI and Arial fonts.

Bold and large headings are used to highlight important
information, while simple body text makes the content
easy to read.

## 3. Layout Strategy

The website uses a clean and responsive layout.

The homepage introduces TechTreasure and highlights
different technology topics. The blog page displays
articles in organized cards.

Rounded corners, hover effects, and glowing colors
make the website look modern and futuristic.

## 4. Website Theme

Cyberpunk Neon – inspired by futuristic technology,
digital environments, and neon lighting.
